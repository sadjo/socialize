# Avec un compte Mastodon

Si l'instance le permet, une personne qui a déjà un compte Mastodon utilise Socialize **sans créer de compte
ici**, depuis l'onglet *Mastodon* de l'écran de connexion.

## Se connecter avec Mastodon

1. Choisissez votre **serveur** (par exemple mastodon.social) et indiquez votre **identifiant**, sans le @ : `alice`
   pour `@alice@mastodon.social`. Une adresse complète `@alice@serveur` fonctionne aussi.
2. *Continuer sur Mastodon* ouvre la page de votre serveur : vous y tapez votre mot de passe, puis vous autorisez
   Socialize.
3. De retour ici, vous êtes connecté.

Les liens sous le formulaire mènent au serveur choisi : *Créer un compte Mastodon* et *Mot de passe Mastodon
oublié ?*.

## Ce qui change avec un compte Mastodon

- **Profil** : ce sont vos publications Mastodon ; le profil se modifie sur votre serveur Mastodon.
- **Fil** : les publications des comptes que vous suivez et que l'instance connaît, comptes d'ici compris.
- **Stories** : celles des comptes d'ici que vous suivez.
- **« J'aime », commentaires et abonnements** passent par votre serveur Mastodon.
- **Abonnés** : si votre compte Mastodon valide lui-même ses abonnés, les demandes venues d'ici s'acceptent ou se
  refusent dans *Demandes*, et un abonné se retire depuis la liste de vos abonnés ; votre serveur Mastodon s'en charge.
- **Notifications** : « J'aime », commentaires, mentions et demandes d'abonnement venus d'ici apparaissent dans
  *Notifications*, comme pour un compte d'ici ; votre application Mastodon vous prévient aussi. Les notifications
  sur l'appareil restent celles de votre application Mastodon.
- **Apparence** : thème et filtre des médias se choisissent ici, dans *Apparence* (menu) ; les autres réglages
  restent sur votre serveur Mastodon.
- **Publier** : les photos, vidéos et textes publiés depuis Socialize partent sur votre compte Mastodon ; l'onglet
  *Texte* publie un message sans média.
- **Import Instagram** : possible si un administrateur l'autorise, depuis *Apparence › Instagram* ; l'archive est
  publiée sur votre compte Mastodon.

Socialize agit avec l'autorisation accordée à la connexion, sans jamais connaître votre mot de passe Mastodon.

## Créer un compte Mastodon

Si l'administrateur l'a prévu, l'écran de connexion propose aussi de créer un compte sur un serveur Mastodon choisi.
