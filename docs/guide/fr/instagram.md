# Instagram

## Publier aussi sur Instagram

*Réglages › Instagram* connecte un compte Instagram **professionnel** (Créateur ou Entreprise, exigé par Instagram).
Des règles choisissent les visibilités pour lesquelles *Publier aussi sur Instagram* est coché d'avance, et si elles
valent pour les stories ; la case reste modifiable à chaque publication.

L'envoi se fait en tâche de fond quand les médias sont prêts. Son état s'affiche sur la publication, avec *Réessayer*
en cas d'échec ; une publication déjà en ligne peut aussi partir après coup. La connexion demande une application
Meta, que l'administrateur de l'instance peut fournir.

## Partager vers Instagram

Sans compte professionnel, **Partager vers Instagram** (menu **⋯** d'une publication, ou *Mes stories*) ouvre le
partage du téléphone avec les photos et les vidéos, et copie la légende : il reste à la coller dans Instagram. Sur
ordinateur, les fichiers se téléchargent.

## Mentionner un compte Instagram

`ig:@nom` dans une légende devient un lien vers ce compte Instagram, et une vraie mention dans la copie envoyée sur
Instagram (voir [Mentions, hashtags et liens](mentions-et-liens.md)).
